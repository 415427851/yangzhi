# 肉鸡养殖场设备建设方案

一个纯文字版的静态介绍网站，用于展示标准化肉鸡养殖场的规模指标、场址要求、
设备配置、建设实施节奏与投资效益测算。

## 页面结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 项目概况：规模指标、场址要求、总体布局、技术路线 |
| `equipment.html` | 设备配置：养殖设备、环控设备、通风清粪、粪污处理、辅助设备 |
| `plan.html` | 建设实施：阶段安排、关键控制点、投产初期管理、人员培训 |
| `cost.html` | 投资与效益：投资估算、年运行成本、效益测算 |
| `assets/style.css` | 全部样式（浅色主题，含移动端与打印适配） |

## 本地预览

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

直接双击 `index.html` 也可以查看，但用本地服务器更接近线上效果。

## 说明

- 站内金额、出栏量、料肉比等均为方案估算口径，仅作说明用途，
  实际落地需以当地造价、工程结算与市场行情复核。
